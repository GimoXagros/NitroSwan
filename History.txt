NitroSwan revision history
-=-=-=-=-=-=-=-=-=-=-=-=-=-

Unreleased (post V0.7.7-custom.r4)
	Implemented the cartridge ROM opcode/immediate-fetch wait state selected by
	I/O register $A0 bit 3. The cached timing flag applies only while the physical
	V30 PC maps cartridge ROM, leaving data reads, RAM, SRAM and BIOS unchanged.
	Confirmed normal Mahjong Touryuumon speed, sound and input on DSpico hardware.
	Corrected the remaining One Piece battle-sky error by recording the selected
	WonderSwan background-color register value as bounded DS backdrop palette events.
	Kept WonderSwan palette RAM color 0, transparent BG entries, OBJ palette handling,
	the existing sprite latch and 4bpp OBJ double buffer unchanged.
	Confirmed the sky gradient and intact character graphics in melonDS; final
	DSpico hardware confirmation remains pending before release.

V0.7.7-custom.r4 - 2026-08-29 (GimoXagros custom build)
	Added the first title-bounded BG scanline palette replay path for From TV
	Animation One Piece - Grand Battle Swan Colosseum. A later post-r4 fix was
	required for the separately selected background-color/backdrop register.
	Recorded palette changes in a bounded triple-buffered delta list without
	expanding EMUPALBUFF or reusing DMA3, which remains dedicated to HBlank windows.
	Latched the target's sprite table at the hardware-compatible line boundary.
	Deferred its 4bpp tile conversion until VBlank updates complete, then prepared
	the next 16KB OBJ tile image in an off-screen VRAM bank and switched it with OAM.
	Kept OBJ palette raster disabled and left every non-target game on the r3 path.
	Verified rapid combat movement in melonDS with normal graphics, speed and sound.

V0.7.7-custom.r3 - 2026-08-23 (GimoXagros custom build)
	Replaced the global DSpico MPU remap with a NitroSwan-only 64KB ROM bank cache.
	Kept NDS_Shared and the BlocksDS memCached()/memUncached() MPU aliases intact.
	Used fixed cache slots for the 15 visible WonderSwan ROM segments so active
	memory-table pointers are never invalidated by cache eviction.
	Added cache invalidation for IPS patches and write-back synchronization for
	WonderWitch flash programming and sector erase operations.
	Kept the standard DS build on the original direct-ROM mapping with no cache
	lookup overhead; the new path is compiled only for DSPICO_3DS_BUILD.
	Added host cache vectors and source regressions for MPU isolation, segment
	mapping, invalidation and flash write-back.

V0.7.7-custom.r2 - 2026-08-14 (GimoXagros custom build)
	Corrected RTC invalid-date handling, month lengths, leap years and rollover.
	Corrected ASWAN RAM to 16KB and ignored writes outside the physical range.
	Added experimental cacheable access to the 3DS debugger RAM used by DSpico;
	this global MPU approach was replaced by the project-local bank cache in r3.
	Restored opt-in, game-bounded idle-loop speed hacks with ARM9 cache coherency.
	Fixed the ROM-load Data abort by keeping opcode redirection on the established
	menu-toggle path instead of forcing it during every cartridge load.
	Aligned the cartridge-load call frame and initialized the Karnak/Sphinx state
	pointer before mapper reset.
	Created /nitroswan and a default settings.cfg automatically on first launch;
	direct path access remains compatible with FAT-hidden folders.
	Resolved direct-launch ROM arguments before settings I/O changes the working
	directory, retained Pico Loader's FAT device, and used bounded ROM reads to
	fix the first-load stall through DSpico.
	Fixed direct-launch save paths so NVRAM, states and cheats stay in /nitroswan.
	Enabled NVRAM autosave by default, exposed its setting, and save on exit.
	Added raw .sav import fallback while retaining native .ram/.eeprom output.
	Restored the proven V0.7.7-custom graphics, audio, REP and ROM-read paths after
	the experimental accuracy changes caused blank video and crackling audio.
	Added automated RTC, RAM, cache and stable hot-path regression checks.
	Included the upstream Karnak reset pointer fix.

V0.7.7-custom - 2026-08-13 (GimoXagros custom build)
	Added a DSi/DSpico compatibility profile for Nintendo 3DS: request the
	134 MHz ARM9 clock and force the stable 60 Hz frame-conversion path.
	Added English, Japanese and Korean menus with persistent language setting.
	Added UTF-8 and legacy CP949 Korean filename decoding.
	Added an embedded Galmuri-derived CJK font styled to match the original
	English menu's white/grey bevel and black shadow.
	Added per-game .cht RAM cheats with optional compare values and safe
	WonderSwan RAM/SRAM address validation.
	Optimized menu-only Unicode rendering with binary font lookup and a hashed
	dynamic glyph cache; normal emulation has no Unicode rendering overhead.
	Fixed raw menu frame tiles being decoded as mystery CJK characters.
	Kept the upstream V0.7.7 emulation core and save/config structure compatible.
